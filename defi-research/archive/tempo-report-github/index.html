Build on Tempo

文档页面建议动作
Getting Funds on Tempo 弄清主网/测试网资金来源与限制；与 Get Testnet Faucet Funds、Bridging 交叉阅读后再动账，避免误操作主网资金。
Create & Use Accounts 按文档完成账户创建与日常使用路径；理解智能账户/权限模型（若有），为后续支付与集成打基础。
Make Payments 走通普通转账、memo、费用赞助等支付流；与 Use Tempo Transactions 中的交易类型能力对照，确保钱包或脚本发的是文档支持的类型。
Private Transactions 阅读隐私功能的适用场景、合规与可用性说明；仅在文档允许的路径下尝试，不假设与主网默认转账相同。
Issue Stablecoins 理解发行流程与角色前提；优先在测试网或文档明示的安全环境演练，再评估主网发行涉及的法律与对手方风险。
Exchange Stablecoins 按文档完成稳定币兑换/流动性相关交互（若对 DEX 或池子有说明），熟悉报价、滑点与代币列表来源（可与 Token List Registry 对照）。
Make Agentic Payments 阅读机器支付/会话或流式支付等协议说明，跑通文档中的最小示例，形成与「代理支付」叙事一致的链上记录（若有测试环境优先）。

Integrate Tempo

文档页面建议动作
Overview 先通读集成总览，建立「连接网络 → 领水/资金 → 发 Tempo 交易 → 部署/验证」的整体路线图，再深入子页。
Connect to the Network 在钱包或节点中配置 RPC、链 ID、浏览器等；保存官方参数来源，避免使用不明第三方端点。
Use Tempo Transactions 重点阅读文档对 EIP-2718 类 Tempo 交易类型的说明；关注 可配置费用代币（如美元计价的 TIP-20 作 gas）、费用赞助（代付 gas）、批量调用（batch）、访问密钥（委托签名）等能力，并在测试网用钱包或脚本各走通至少一条与自身场景相关的路径。
Get Testnet Faucet Funds 领取测试代币后，刻意覆盖不同交易形态（普通转、带 memo、赞助费、批量等），与上文 Tempo Transactions 文档交叉验证。
EVM Differences 逐项对照以太坊开发习惯与 Tempo 差异（预编译、opcode、费用、交易类型等），减少「能部署但发不出交易」的无效交互。
Predeployed Contracts 熟悉链上预部署合约地址与用途；集成或调用时优先使用文档列出的标准入口，避免硬编码未文档化的地址。
Token List Registry 理解官方或社区代币列表的注册与拉取方式；支付/兑换前核对代币元数据与精度，防止错误授权或假币。
Wallet Developers 若你维护钱包：按钱包开发者指南接入 Tempo 交易类型、费用代币与赞助逻辑；否则可略读以理解钱包端能力边界。
Contract Verification 若有部署合约：按文档完成验证，便于他人审计与你自己复盘；亦有助于形成「开发者型」链上/索引痕迹（仍无空投保证）。
Bridging 在理解桥接资产类型与终局时间的前提下，按文档完成一次跨链入金/出金（注意手续费与流动性）；与 Getting Funds 章节一起读。
Ecosystem 浏览生态项目与工具清单，挑选 1～2 个与支付场景相关的应用做真实试用，避免只与裸链交互而完全脱离生态。

与「空投预期」相关的理性策略

1. 优先可解释性：链上足迹若能对应「真实用户或开发者行为」（钱包、测试网探索、主网支付、小型集成），比大量同质、短时间窗口的机械重复更经得起事后规则筛选（若有）。

2. 控制成本与合规：主网行为涉及真实资金与税务/合规；测试网亦应遵守水龙头与社区规则。多号、自动化刷量可能触发反女巫或违反条款，且与文档倡导的支付场景无关。
